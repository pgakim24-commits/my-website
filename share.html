💬 카카오톡 오픈채팅방에 공유하는 방법

  1. 위 카드에서 공유하고 싶은 페이지의 복사 버튼을 누릅니다
  2. 카카오톡 앱을 열고 공유할 오픈채팅방으로 이동합니다
  3. 채팅 입력창을 길게 누른 뒤 붙여넣기를 선택합니다
  4. 전송 버튼을 누르면 잠시 후 썸네일 미리보기가 자동으로 나타납니다
💡 휴대폰으로 보고 있다면?
복사 → 카카오톡 전환 → 오픈채팅방 → 입력창 길게 눌러서 붙여넣기 → 전송

💡 PC 카카오톡이라면?
복사(Ctrl/⌘+C) → 카카오톡 채팅방 클릭 → 입력창에 붙여넣기(Ctrl/⌘+V) → Enter

🆕 오픈채팅방을 새로 만들고 싶다면?

  1. 카카오톡 → 하단 채팅 탭 또는 오픈채팅 탭으로 이동
  2. 우측 상단 + 아이콘 → 오픈채팅 만들기 선택
  3. 그룹 채팅방 / 1:1 채팅방 / 오픈 프로필 중 선택
  4. 방 이름, 소개, 커버 이미지 설정 후 완료
  5. 생성된 방의 공유 링크를 친구나 SNS로 보내 초대
💡 만든 오픈채팅방 링크를 위의 사이트 URL과 함께 공유하면, 사람들이 사이트도 보고 채팅방에도 참여할 수 있어요.
